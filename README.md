# Hand Gesture Virtual Mouse & Keyboard

This project is a complete **hand gesture-controlled virtual mouse and keyboard system** using Python, OpenCV, MediaPipe, and PyAutoGUI. It allows users to control the mouse, click, scroll, and even type using gestures—all without touching a physical device.

## ✨ Features

- 🖱️ **Virtual Mouse Control** (move cursor with index finger)
- 👆 **Left Click** using thumb + index gesture
- 📜 **Scroll Up/Down** with custom gestures
- ⌨️ **On-screen Keyboard** with support for:
  - Alphabets
  - Shift key (for uppercase)
  - Space
  - Backspace
  - Enter

## 🧠 Technologies Used

- [OpenCV](https://opencv.org/) – for image processing and drawing
- [MediaPipe](https://google.github.io/mediapipe/) – for real-time hand tracking
- [PyAutoGUI](https://pyautogui.readthedocs.io/) – for controlling the mouse and keyboard
- [NumPy](https://numpy.org/) – for calculations
